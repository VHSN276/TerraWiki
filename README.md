# TerraWiki

Guia interativo de progressão de Terraria, com roadmap por classe, árvores de criação e catálogo de itens. O site é feito com HTML, CSS e JavaScript e não precisa de etapa de build para ser aberto ou hospedado.

## Abrir localmente

Abra `TerraWiki.html` em um navegador. Para compartilhar o site e evitar as restrições que alguns navegadores aplicam a arquivos locais, publique-o em um servidor HTTPS.

## Publicar com GitHub Pages

O `index.html` da raiz encaminha para `TerraWiki.html`, então a página inicial do site pode usar o endereço principal publicado pelo GitHub Pages. Para ativar a publicação, abra **Settings → Pages**, selecione **Deploy from a branch**, escolha `main` e a pasta `/(root)`.

## Observações

- O progresso é salvo localmente no navegador. Ele não sincroniza entre dispositivos.
- Algumas imagens e páginas da wiki dependem de conexão com a internet.
- O arquivo pode ser instalado como PWA em navegadores compatíveis depois de receber manifesto, ícones e suporte offline. Esses recursos ainda não fazem parte desta versão.
